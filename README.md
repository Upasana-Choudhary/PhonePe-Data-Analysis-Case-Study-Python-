# 📊 PhonePe Data Analysis Case Study

## 📌 Project Overview

This case study analyzes **PhonePe transaction and user data** to uncover trends in digital payment adoption across Indian states.
The objective is to derive **data-driven insights** related to transactions, user growth, app usage patterns, and regional behavior.

This project demonstrates skills in **data cleaning, exploratory data analysis (EDA), visualization, and insight generation** using Python.

---

## 🧠 Problem Statement

With the rapid growth of digital payments in India, understanding **state-wise transaction behavior and user adoption trends** is crucial.
This analysis answers questions such as:

* How do transactions and users vary across states?
* Which states show higher app usage trends?
* How does population and user ratio influence adoption?
* What patterns emerge over time?

---

## 🗂️ Dataset Description

The dataset contains state-wise information related to:

* Transaction count and transaction amount
* Registered users
* App usage metrics
* Time-based data (year/quarter)

📁 **Source:** PhonePe Pulse (publicly available dataset) https://github.com/Upasana-Choudhary/PhonePe-Data-Analysis-Case-Study-Python-/blob/main/phonepe-pulse_raw-data_q12018-to-q22021-v0-1-5-1720351752.xlsx

---

## 🛠️ Tools & Technologies Used

* **Python**
* **Pandas** – data manipulation
* **NumPy** – numerical operations
* **Matplotlib & Seaborn** – data visualization
* **Jupyter Notebook** – analysis environment

---

## 🔍 Analysis Performed

* Data cleaning and preprocessing
* State-wise comparison of transactions and users
* Trend analysis using line plots
* App usage analysis over time
* Population vs user ratio insights
* Identification of high-growth and low-adoption states

---

## 📈 Key Insights

* States with higher digital infrastructure show significantly higher transaction volumes.
* App usage demonstrates a **consistent upward trend**, indicating increasing digital adoption.
* User-to-population ratio highlights disparities in adoption across states.
* Seasonal spikes suggest higher usage during festive or financial periods.
